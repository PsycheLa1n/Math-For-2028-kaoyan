# 七种未定式的计算

> 求极限的核心考点。总原则一句话：**把任意未定式化为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$，再用洛必达 / 等价无穷小 / 泰勒展开解决。**

---

## 一、七种未定式

| 编号 | 类型 | 形式 |
|------|------|------|
| 1 | 零比零 | $\frac{0}{0}$ |
| 2 | 无穷比无穷 | $\frac{\infty}{\infty}$ |
| 3 | 零乘无穷 | $0 \cdot \infty$ |
| 4 | 无穷减无穷 | $\infty - \infty$ |
| 5 | 零的零次方 | $0^0$ |
| 6 | 一的无穷次方 | $1^\infty$ |
| 7 | 无穷的零次方 | $\infty^0$ |

---

## 二、核心转化关系

```
0·∞  ──取倒数──▶  0/0 或 ∞/∞
∞−∞  ──通分/有理化/提因子──▶  0/0 或 ∞/∞
0⁰、1^∞、∞⁰  ──取对数──▶  0·∞  ──▶  0/0 或 ∞/∞
```

**前两种（$\frac{0}{0}$、$\frac{\infty}{\infty}$）是"母形式"，其余五种都要化成它们。**

---

## 三、必备工具

### ① 等价无穷小（x → 0，必背）

| 关系 | 公式 |
|------|------|
| 正弦 | $\sin x \sim x$ |
| 正切 | $\tan x \sim x$ |
| 反正弦 | $\arcsin x \sim x$ |
| 反正切 | $\arctan x \sim x$ |
| 对数 | $\ln(1+x) \sim x$ |
| 指数 | $e^x - 1 \sim x$ |
| 余弦 | $1 - \cos x \sim \frac{x^2}{2}$ |
| 幂函数 | $(1+x)^a - 1 \sim ax$ |
| 指数底数 | $a^x - 1 \sim x \ln a$ |

### ② 两个重要极限

$$\lim_{x \to 0}\frac{\sin x}{x} = 1, \qquad \lim_{x \to \infty}\left(1 + \frac{1}{x}\right)^x = e$$

### ③ 常用泰勒展开

$$\sin x = x - \frac{x^3}{6} + o(x^3)$$
$$e^x = 1 + x + \frac{x^2}{2} + o(x^2)$$
$$\ln(1+x) = x - \frac{x^2}{2} + o(x^2)$$
$$\cos x = 1 - \frac{x^2}{2} + o(x^2)$$

---

## 题型 1：0/0 型

**解题思路**
1. 先尝试**等价无穷小替换**（乘除可直接换，加减要谨慎）
2. 替换后仍是 $\frac{0}{0}$，用**洛必达**（分子分母分别求导）
3. 洛必达失效或越导越复杂，改用**泰勒展开**

**例题**：求 $\displaystyle \lim_{x \to 0}\frac{1 - \cos x}{x^2}$

**详细解答**

方法一（等价无穷小）：由 $1 - \cos x \sim \frac{x^2}{2}$，得
$$\lim_{x \to 0}\frac{1 - \cos x}{x^2} = \lim_{x \to 0}\frac{x^2/2}{x^2} = \frac{1}{2}$$

方法二（洛必达，连续两次）：
$$\lim_{x \to 0}\frac{1 - \cos x}{x^2} = \lim_{x \to 0}\frac{\sin x}{2x} = \lim_{x \to 0}\frac{\cos x}{2} = \frac{1}{2}$$

---

## 题型 2：∞/∞ 型

**解题思路**
- 直接用**洛必达**，本质是比较分子分母的增长速度
- 多项式型可"抓大头"（只保留最高次项）

**例题**：求 $\displaystyle \lim_{x \to +\infty}\frac{x^2}{e^x}$

**详细解答**

洛必达两次：
$$\lim_{x \to +\infty}\frac{x^2}{e^x} = \lim_{x \to +\infty}\frac{2x}{e^x} = \lim_{x \to +\infty}\frac{2}{e^x} = 0$$

> 结论：指数函数增长快于任何多项式，所以极限为 0。

---

## 题型 3：0 · ∞ 型

**解题思路**
- 把其中一个因子**取倒数**放到分母，化成 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$
- 原则：把"简单"的取倒数，把"复杂"的留分子（方便后续求导）

**例题**：求 $\displaystyle \lim_{x \to 0^+} x \ln x$

**详细解答**

把 $x$ 取倒数放到分母：
$$x \ln x = \frac{\ln x}{1/x} \quad (\text{此时是 } \frac{\infty}{\infty})$$

洛必达：
$$\lim_{x \to 0^+}\frac{\ln x}{1/x} = \lim_{x \to 0^+}\frac{1/x}{-1/x^2} = \lim_{x \to 0^+}(-x) = 0$$

---

## 题型 4：∞ − ∞ 型

**解题思路**
三种手段，任选其一，目的是化成 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$：
1. **通分**（分式相减）
2. **有理化**（含根式）
3. **提公因子**

**例题**：求 $\displaystyle \lim_{x \to 0}\left(\frac{1}{\sin x} - \frac{1}{x}\right)$

**详细解答**

通分：
$$\frac{1}{\sin x} - \frac{1}{x} = \frac{x - \sin x}{x \sin x}$$

分子用泰勒展开 $x - \sin x = \frac{x^3}{6} + o(x^3)$，分母 $x \sin x \sim x^2$，于是
$$\lim_{x \to 0}\frac{x - \sin x}{x \sin x} = \lim_{x \to 0}\frac{x^3/6}{x^2} = 0$$

---

## 题型 5：0⁰ 型

**解题思路**
- 设 $y = f(x)^{g(x)}$，**取对数** $\ln y = g(x)\ln f(x)$，变成 $0 \cdot \infty$
- 再化成 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 求出 $\lim \ln y = A$，则 $\lim y = e^A$

**例题**：求 $\displaystyle \lim_{x \to 0^+} x^x$

**详细解答**

令 $y = x^x$，取对数 $\ln y = x \ln x$。由题型 3 知：
$$\lim_{x \to 0^+} x \ln x = 0$$

所以
$$\lim_{x \to 0^+} x^x = e^0 = 1$$

---

## 题型 6：1^∞ 型

**解题思路**
- **首选快捷公式**：当 $f(x) \to 1$，$g(x) \to \infty$ 时，
$$\lim f(x)^{g(x)} = e^{\lim g(x)[f(x)-1]}$$
- 或取对数化成 $0 \cdot \infty$ 再处理

**例题**：求 $\displaystyle \lim_{x \to \infty}\left(1 + \frac{2}{x}\right)^x$

**详细解答**

记 $f(x) = 1 + \frac{2}{x} \to 1$，$g(x) = x \to \infty$。用公式：
$$\lim g(x)[f(x)-1] = \lim_{x \to \infty} x \cdot \frac{2}{x} = 2$$

所以
$$\lim_{x \to \infty}\left(1 + \frac{2}{x}\right)^x = e^2$$

---

## 题型 7：∞⁰ 型

**解题思路**
- 设 $y = f(x)^{g(x)}$，**取对数** $\ln y = g(x)\ln f(x)$，此时是 $0 \cdot \infty$
- 化成 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 求 $\lim \ln y = A$，则 $\lim y = e^A$

**例题**：求 $\displaystyle \lim_{x \to +\infty} x^{1/x}$

**详细解答**

令 $y = x^{1/x}$，取对数 $\ln y = \frac{\ln x}{x}$。这是 $\frac{\infty}{\infty}$ 型，洛必达：
$$\lim_{x \to +\infty}\frac{\ln x}{x} = \lim_{x \to +\infty}\frac{1/x}{1} = 0$$

所以
$$\lim_{x \to +\infty} x^{1/x} = e^0 = 1$$

---

## 四、总结口诀

> **先看型，再转化；化成 0/0 和 ∞/∞；洛必达、等价、泰勒上。**

| 类型 | 关键动作 |
|------|---------|
| $\frac{0}{0}$ | 等价无穷小 / 洛必达 / 泰勒 |
| $\frac{\infty}{\infty}$ | 洛必达 |
| $0 \cdot \infty$ | 取倒数 → 0/0 或 ∞/∞ |
| $\infty - \infty$ | 通分 / 有理化 / 提因子 |
| $0^0$ | 取对数 → 0·∞ |
| $1^\infty$ | 公式 $e^{\lim g(f-1)}$ |
| $\infty^0$ | 取对数 → 0·∞ |
